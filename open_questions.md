# Missing evidence and verification experiments

These are research gaps, not prerequisites imposed on unrelated development. Evidence cutoff: 2026-10-27.

| Priority | Question / observed gap | Concrete verification | Interpretation boundary |
|---|---|---|---|
| 1 | Why does the four-interface student fail even on training references? | Align teacher/student by reference and phase; measure first contact, first lift, action disagreement and subsequent loss. Compare more optimization with unchanged data. | Distinguish underfitting from partial observability and target ambiguity. |
| 1 | Does a fixed command identify the teacher's dynamic behavior? | Hold object and wrist trajectory fixed; collect multiple independently successful contact configurations and teacher actions for each command. Intervene on commands at identical states. | A command swap is not automatically physically feasible. |
| 1 | FORM means opening in E07 but closing/contact acquisition in some older APIs. | Explicitly document current behavior; train a separate contact-establishment stage with matched update budget and compatible runtime. | Do not relabel an old checkpoint and claim its semantics changed. |
| 1 | Real-robot success has no repeated checkpoint-linked record. | Log named objects, requested command, checkpoint, synchronized tactile/kinematic feedback and video; report lift, 1 s/5 s retention and failure counts. | User feedback is qualitative; read-only workflow is not a grasp trial. |
| 1 | Agent-generated commands are not evaluated by E07. | Freeze one trained controller for an experiment; compare reference-derived and independently agent-selected commands under the same approach/objects. Log command validity, physical feasibility and task outcome separately. | No zero-shot claim from reference-derived commands. |
| 2 | Random grouping versus pose grouping has one training seed. | Repeat both grouping construction and training with matched budgets; use task/parent paired resampling within seed and report between-seed variability. | Existing paired confidence intervals condition on a single trained model. |
| 2 | Manifold-guided demonstration selection loses its small-test advantage. | Inspect selected motion/contact transitions; compare phase-aware trajectory selection with static coverage at equal demonstrations and teacher queries. | Coverage alone is not a manipulation objective; E10 does not prove equivalence. |
| 2 | Geometry-based near-contact is not measured contact. | Save link/object contact positions, normals, forces and IDs during rollout; compare contact consistency and switching with geometric distances. | Existing five-finger signatures cannot establish force closure. |
| 2 | Low valid-joint fractions in some SPIDER subsets. | Audit units, model limits, joint conventions and retarget settings against source examples, then rerun affected statistics. | Do not silently permute joints or treat the filtering effect as a capability difference. |
| 2 | Human / Wuji / Sharpa representations differ. | Confirm Wuji anatomical channels against video; compare common normalized landmarks and dynamic retarget error, then physical interaction. | Current PCA dimensions and FK error do not establish transferable contact. |
| 2 | Native object frames are not semantically canonicalized. | Compare shape-axis alignment and symmetry-aware distances, keeping object identity and normalization visible. | Object-local coordinates alone do not align heterogeneous affordances. |
| 2 | Open-hand initialization changes in-hand task intent. | Separate tabletop acquisition, pre-grasped manipulation and supported interaction; evaluate under both intended and altered resets. | E10 broad open-start failure is not a general measure of teacher quality. |
| 2 | New tools and object geometry remain weakly tested. | Use object-disjoint hammer/scoop/elongated and box-shaped objects; control EEF trajectory and compare target adherence and contact retention. | Parent-held-out is not object-held-out. |
| 3 | Pose-bank kinematic validity lacks collision checking. | Test selected representatives in the correct articulation and collision assets; report self-intersection, object penetration and stable-contact feasibility separately. | Joint-limit validity and clipped FK reconstruction are insufficient. |
| 3 | Dataset counts represent different snapshots and units. | Reconcile raw trajectory → parent → segment → used-reference tables when updating training; preserve source identity. | No subtraction across raw trajectories, windows and environment slots. |
| 3 | Automatic skill registration/training and Real2Sim verification are incomplete. | Implement one bounded new-skill registration example, with its loader, runtime semantics and measured result. | Existing registry hooks are not autonomous test-time learning. |
