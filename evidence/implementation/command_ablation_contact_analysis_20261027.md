# Command Ablation：Contact Signature 与抓起后 Survival

分析日期：2026-10-27。使用已有1232条真实仿真rollout（Teacher/E0/E1/E2各308），没有重新训练，也没有用reference姿态替代执行接触。每模型包含28条任务×11个case：原位、整体空间变化、物体相对初态误差。

## 结论

1. 当前五指二值接触下，E2姿态聚类没有显示出比E1随机固定分组更高的类内一致性或类间区分度。即便限定到两者都成功抓起的209个case，也没有改变这个结论。
2. E1的长时保持优势伴随更少接触中断、更低接触力变异系数，以及更多有效接触手指。对同一批209个共同成功case比较后，趋势仍然存在，因此不完全是“E1成功任务不同”导致的平均值差异。但这仍是相关性解释，不是因果验证。
3. 抓起后5秒条件生存率：E1 80.0%，E2 74.7%，Teacher 69.5%，E0 62.2%。未成功抓起的任务单独计数，不进入条件生存曲线。
4. 本分析不能证明随机类别具有功能语义，也不能证明原始姿态manifold不存在价值。只有单个训练seed、一次随机标签划分；五指二值接触分辨率有限，且策略与分组同时变化。

## 数据字段和不可计算项

已有NPZ字段包括：`object_contact_N[T,5]`、`tip_force_N[T,5,3]`、手指/手腕关节、物体位姿、phase、初始物体高度。每条270帧，控制频率30Hz。

- `object_contact_N`是过滤目标物体后的手指接触强度，聚合该手指碰撞link；用于判断有效物体接触及接触力变化。
- `tip_force_N`是未裁剪的指尖传感器三维力；与物体过滤后的全手指聚合量不同。
- 没有保存逐link接触、接触点、接触法向，也没有足够信息还原物体局部接触区域。
- 因此本轮实现[b_i,F_i]，不伪造ℓ_i。不能直接计算几何“对向接触”。单独报告“拇指与至少一个其他手指同时接触”的代理量，它不等价于对向法向、力闭合或稳定抓握。

## 定义

有效接触 `b_i(t) = object_contact_N_i(t) >= 0.5 N`。手指顺序为thumb/index/middle/ring/little。

首次成功抓起：物体高于初始高度至少2cm，且至少两根手指有效接触，连续15帧（0.5秒），以确认帧为时间零点。该标签逐条与原物理评测JSON核对，全部一致。

成功抓起的离散signature：在首次成功抓起的连续15帧窗口内，某根手指接触占比≥50%则置1。这样对齐实际抓起事件，避免将不同任务相同FORM时刻误认为相同接触阶段。它描述抓起时的接触结构，不代表整个episode接触不变。

类内一致性为平均Jaccard similarity；类间为平均Jaccard distance，并额外给出归一化Hamming距离。仅比较不同原始任务，同类扰动类型内配对，先平均每对任务的rollout比较，再对任务对等权平均，避免成功重复次数多的任务占据主要权重。E1使用其固定随机类别，E2使用原始姿态类别；不把两者的C编号解释为相同语义。

HOLD稳定性窗口：reference结束后5秒（第90至239帧）。每指连续离开有效接触≥3帧（0.1秒），且此前在接触，记一次中断；从未接触不计中断，窗口起点已不接触也不计一次新中断。力CV为每指有效接触帧的标准差/均值，至少两帧才定义，再按指、rollout平均；CSV同时保留含零接触帧的CV。没有可用接触帧的CV为空，不填0。

抓起后首次失稳：成功抓起后，`高度>=2cm且有效手指>=2`连续失效≥6帧（0.2秒），以确认帧计事件。这比原“跌至初态+1cm”的掉落标准更敏感，可能在尚未掉落时识别接触失稳。允许瞬时小于0.2秒的中断；失稳后即使恢复也不重新进入survival风险集。RELEASE开始时仍未失稳者右删失。

左图采用Kaplan–Meier，时间从各自首次确认成功抓起算起；RELEASE右删失。本批在5秒之前没有成功但被右删失的case，因此5秒值同时等于实际持续成功数/成功抓起数。右图是左图乘以抓起比例，未抓起贡献为0；它是相对各自抓起事件对齐的整体成功概率，不是从episode开始的公共时钟。

5秒仍未失稳的数量分别为180、145、200、189。它们不等于先前reference结束后5秒HOLD通过数：起点不同、允许短暂失稳的规则不同，且本survival一旦失败不允许恢复。前面hold_contact_timeline右图另给出从reference结束算起的全任务公共时钟表现。

首次形成持续0.5秒多指接触的确认时间中位数，四模型均为约2.067秒；只在各自形成该接触的case中计算，失败不能当成零耗时。逐任务耗时已保存在CSV。

## 限制与下一步

- 28个原始任务各11个case不是308个独立任务；当前曲线和接触表为描述性统计，不据此宣称显著提升。
- 力CV只在接触存在时有定义，需要和无接触时间/中断次数共同解释，不能单独作为优劣指标。
- 目前是不同标签训练得到的不同策略之间比较；若要独立检验分类是否有功能意义，可再对同一组固定Teacher rollout分别套用E1和E2标签计算signature分离度，避免策略差异混入。
- 若需要link/物体区域分辨率，可以在以后评测增加逐link接触记录再重放相同case，无需重新训练；当前没有回推未记录的字段。
