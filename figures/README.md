# Main report figures

The concise report uses only `method_overview`, `main02_manifold`, `main03_distillation`, and `main04_demonstrations` (PNG/SVG/PDF). `build_rldex_report.py` regenerates these four from local sources.

- **Main 1:** user-provided `../method.pdf`, preserved as `method_overview.pdf` and rendered to SVG/PNG with Poppler. Proposed skill expansion and illustrative execution settings are qualified in the main caption.
- **Main 2:** large projected HOI manifold with the source palette read directly from `manifold.html`. Six hand-image callouts terminate at the actual medoid sample coordinates. Uses the interactive initial yaw/pitch and projection formula. `data/figure2_medoid_annotations.json` records each cluster, trajectory, source color and coordinate. Variance/collection-scale analysis remains in the tables and extended figures.
- **Main 3:** supported command definitions and teacher/student learning responsibilities; no synthetic performance data.
- **Main 4:** six actual Isaac Sim teacher lift snapshots, one per final link-near cluster. Source: `assets/cluster_teacher_rollouts/manifest.json`; mapped metadata in `data/cluster_teacher_demos.json`. These replace the earlier saved-state cube/banana illustrations. Last-30-tick HOLD is distinct from five-second HOLD and from agent success.

The `fig01`–`fig07`, `figS01` and `equation_*` assets serve the extended report. New mathematical renderings use `main_equation_*` to avoid changing supplementary equations.
